# Сумма массива через Fork/Join

## Задача

Нужно просуммировать большой массив в памяти. Это CPU-bound task (задача, ограниченная процессором): поток не ждёт сеть или диск, а выполняет вычисления. Массив можно делить на независимые диапазоны, считать их параллельно, а частичные суммы складывать.

## Почему Fork/Join

- последовательный цикл прост, но использует одно ядро;
- фиксированный пул подходит для заранее известных независимых задач, однако здесь новые диапазоны естественно возникают во время рекурсивного деления;
- virtual threads полезны для множества блокирующих I/O-задач, но не добавляют процессорных ядер;
- `ForkJoinPool` предназначен для множества коротких вычислительных подзадач и перераспределяет их между workers через work stealing (перехват работы).

`ParallelArraySum.SumTask` наследует `RecursiveTask<Long>`, потому что задача возвращает результат. Пока диапазон больше `threshold`, она делит его пополам. Один диапазон отправляется через `fork()`, второй вычисляется текущим worker, затем `join()` возвращает результат первой части.

`threshold` (порог дробления) определяет минимальный размер последовательной части. Слишком маленькое значение создаёт лишние объекты и расходы на планирование; слишком большое оставляет мало работы для параллельного выполнения.

## Запуск

Из корня репозитория:

```bash
mvn test
```

Запуск демонстрации из каталога модуля:

```bash
mvn package
java -cp target/classes io.github.tantarin.concurrency.forkjoin.ForkJoinDemo
```
