# Runnable vs. Callable

Нужно узнать размер файла в фоновой задаче. `Runnable` удобен, если достаточно выполнить действие: его `run()` возвращает `void` и не объявляет checked exceptions. Поэтому результат приходится записывать во внешнее состояние, а `IOException` — оборачивать.

`Callable<Long>` описывает вычисление: `call()` возвращает `Long` и может объявить `Exception`. После `submit()` результат или ошибка доступны через `Future<Long>`.

Запуск всех тестов из корня репозитория:

```bash
mvn test
```
