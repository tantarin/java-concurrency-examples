# Ограниченный буфер через wait/notifyAll

Producer (производитель) должен ждать, пока в заполненном буфере появится место, а consumer (потребитель) — пока в пустом буфере появится элемент.

Оба условия защищены монитором одного `BoundedBuffer`. Методы проверяют условия в `while`, вызывают `wait()` и после изменения состояния вызывают `notifyAll()`.

В прикладном коде для такой задачи обычно выбирают готовую `BlockingQueue`. Этот модуль реализует буфер вручную, чтобы показать точный контракт monitor wait set.

Из корня репозитория:

```bash
mvn test
```
